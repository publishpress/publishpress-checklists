# Exclude Taxonomy Terms (Pro)

This feature requires the Pro version of the PublishPress Checklists plugin.

In the Pro version of the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, it is possible to disable certain tasks if a post has specific taxonomy terms attached. For example, you can disable a task on Posts and that have a Tag or Category of your choice.

In the screenshot below, both “Sports” and “News” categories are selected for the “Exclude Taxonomies” option. This means that the “Number of words in content” task will not be active for any posts with these categories attached.

![Exclude Taxonomy Terms](https://docs-media.publishpress.com/publishpress-checklists/exclude-taxonomies-bd3315a8d2.webp)

This feature can be enabled or disabled using the “Enable User Roles Filter” by going to Checklists > Settings > General in your WordPress admin area. You can choose the taxonomies that are available in this setting by going to Checklists > Settings > Post Types.
