# All images have Alt text

With the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can require that all the images in your WordPress content have ALT text added. If an image is missing the ALT text, you can choose to show a warning, or prevent the post from being published.

ALT text (short for “alternative text”) is useful because it describes images to visitors who are unable to see them. Visually impaired users often use screen readers that can read ALT text to better understand an on-page image.

- Go to the Image tab. The image below shows the ALT text options.
- You can choose from “Disabled, Recommended, or Required” options.

In the Pro version of [PublishPress Checklists](https://publishpress.com/links/checklists), there is a related task called “Number of characters in Alt text” that allows you to specify the length of the Alt text for images.

![Alt text checklists](https://docs-media.publishpress.com/publishpress-checklists/alt-text-settings-66e488442c.webp)

*Alt Text For All*

If you enable the ALT text option, it will be visible when you edit content. If your images are missing ALT text, this task will be marked in red in the sidebar:

![Alt Text Red](https://docs-media.publishpress.com/publishpress-checklists/alt-text-red-ef3203d233.webp)

*Alt Text Red*

If all your images have ALT text, this task will be marked in green in the sidebar:

![Alt Text Green](https://docs-media.publishpress.com/publishpress-checklists/alt-text-green-53fe8a2951.webp)

*Alt Text Green*

If you’re using the WordPress block editor, any image with missing Alt text will be easy to see. Those blocks will be marked with a red warning icon.

![Missing alt text blocks](https://docs-media.publishpress.com/publishpress-checklists/alt-text-missing-36ddf9beee.webp)
