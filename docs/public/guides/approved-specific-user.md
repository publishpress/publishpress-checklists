# Approved by a specific user (Pro)

This feature requires the Pro version of the PublishPress Checklists plugin.

With this requirement, you can stop content from being published unless it has been approved by a specific user. This feature is available in the Pro version of [PublishPress Checklists](https://publishpress.com/links/checklists).

This is an excellent way to allow some users to “sign off” on content before it is published.

- Click the “Approval” tab. The screenshot below shows the approved by user option.
- You can choose from “Disabled, Recommended, or Required” options.
- In the final box, you can choose which roles can approve posts. In the image below, posts can’t be published unless they are approved by an Administrator or Editor.

![Approved by a specific user](https://docs-media.publishpress.com/publishpress-checklists/approved-user-specific-3b899b066c.webp)

*Approver By User Role*

In the “Options” area, you can choose which users are able to approve this post:

![Who can approve this post?](https://docs-media.publishpress.com/publishpress-checklists/approved-user-05dbe5958c.webp)

If a user is allowed to approve a post, they will see a checkbox like the one shown below. The checkbox only needs to be checked by one of these users.

![Approved by a specific user red](https://docs-media.publishpress.com/publishpress-checklists/approved-specific-wp-user-498d197585.webp)

*Disabled Checkbox User Role*

If the user approves the post, they can check the box and the content can be published.

![Approved by a specific user green](https://docs-media.publishpress.com/publishpress-checklists/approved-user-specific-green-b4cc921453.webp)
