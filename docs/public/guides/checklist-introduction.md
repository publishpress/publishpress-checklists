# Getting Started With PublishPress Checklists

Table of Contents

- [Installing PublishPress Checklists](#h-installing-publishpress-checklists)
- [Enabling the Checklists](#h-creating-the-checklists)
- [Using the Checklists](#h-using-the-checklists)

Using the [PublishPress Checklists](https://publishpress.com/checklists) plugin, you can define tasks that must be complete before content is published. As writers complete each task, [PublishPress Checklists](https://publishpress.com/links/checklists) will mark it as complete. One common use-case is that you can make sure your posts have a minimum or maximum number of words. Another is that you can ensure that all your posts have a featured image.

This is a guide to installing and using the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin.

These guides have useful background information as you’re getting started:

- [Technical requirements for our plugins](https://publishpress.com/knowledge-base/technical-requirements/).
- [How to move from Free to Pro plugins](https://publishpress.com/knowledge-base/how-to-move-from-free-to-pro-plugins/).

## Installing PublishPress Checklists [#](#h-installing-publishpress-checklists)

- Install the PublishPress Checklists.
- Click “Checklists” then “Settings” in your WordPress admin menu.
- Here you can select what content types you want to use with the Checklists.

![](https://docs-media.publishpress.com/publishpress-checklists/checklists-settings-post-types-e23426186f.webp)

## Enabling the Checklists [#](#h-creating-the-checklists)

Next, you can choose the requirements for your checklists.

- Go to “Checklists” then “Checklists” in you WordPress admin menu.
- Choose your post type. In the image below, you can choose checklists for Posts. Other content types will show if you selected them in the “Settings” area.

For each content type, you can create a unique checklist:

![Checklists main screen](https://docs-media.publishpress.com/publishpress-checklists/checklists-screen-b17fe6a1ad.webp)

*Checklist Tasks*

All the tasks are disabled by default. You can select only the requirements you need.

In the center column, you can choose a specific action for each requirement. If you choose the “Required” option, it will be impossible to publish without completing the task. If you choose “Recommended”, a warning will show, but users can still publish.

- Disabled
- Recommended
- Required

![](https://docs-media.publishpress.com/publishpress-checklists/disable-required-c3af4020b2.webp)

## Using the Checklists [#](#h-using-the-checklists)

When you create new content, you will see the Checklists button in the top right corner of the screen, as in the image below:

![New checklists icon](https://docs-media.publishpress.com/publishpress-checklists/new-checklists-icon-b6f192b729.webp)

When you click “Publish” or “Checklists”, you will see the tasks that must be completed before you make the content public. If you see a red warning sign, the post is not ready to publish.

![](https://docs-media.publishpress.com/publishpress-checklists/new-checklists-icon-tasks-5d75865229.webp)

If a particular block is responsible for a failed task, PublishPress Checklists will highlight the problem block, as in this screenshot:

![Problem block with Checklists](https://docs-media.publishpress.com/publishpress-checklists/alt-text-missing-36ddf9beee.webp)
