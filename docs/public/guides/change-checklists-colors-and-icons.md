# Change Checklists Colors and Icons

By default, the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin uses green for completed tasks and red for incomplete tasks. This can be customized by going to “Checklists” then “Settings” and clicking the “Appearance” tab.

On this screen you can replace both the “Complete” and “Incomplete” icons with your choice of [Dashicon](https://developer.wordpress.org/resource/dashicons/). It’s also possible to change the color of the icons.

![Appearance tab](https://docs-media.publishpress.com/publishpress-checklists/change-icons-53adf78c29.webp)

For example, in this next screenshot we have changed the colors. We’ve also changed the dashicons to use `dashicons-thumbs-up` for complete tasks and `dashicons-thumbs-down` for incomplete tasks.

![Changed colors and icons](https://docs-media.publishpress.com/publishpress-checklists/checklist-tasks-changed-75ac5d8015.webp)
