# Featured image is added

With the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can require that all your posts have a Featured image. If the image is missing, you can choose to show a warning, or prevent the post from being published.

Many sites require a featured image for blog posts because an image is important for sharing on social media.

- Click the “Featured Image” tab. The image below shows the “Featured Image is added” option.
- You can choose from “Disabled, Recommended, or Required” options.
- You can choose “Who can ignore this task?”

![](https://docs-media.publishpress.com/publishpress-checklists/featured-image-task-1-15fd2d73a8.webp)

*Featured Image*

If you enable this Featured image option, it will be visible when you edit content. If your Featured image box is empty, this task will be marked in red in the sidebar:

![Featured Image Empty](https://docs-media.publishpress.com/publishpress-checklists/featured-image-empty-ae96b2a6c2.webp)

*Featured Image Empty*

If your Featured image box has an image, this task will be marked in green in the sidebar:

![Featured Image Green](https://docs-media.publishpress.com/publishpress-checklists/featured-image-green-206de6209e.webp)

*Featured Image Green*
