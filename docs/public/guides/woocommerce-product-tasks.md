# WooCommerce product tasks (Pro)

This feature requires the Pro version of the PublishPress Checklists plugin.

One of the features in the Pro version of [PublishPress Checklists](https://publishpress.com/links/checklists) is support for WooCommerce products.

If these requirements are not met, you can choose to show a warning, or prevent the product from being published.

Here is a list of all the tasks available for WooCommerce products:

- Check the “Virtual” box
- Check the “Downloadable” box
- Enter a “Regular price”
- Enter a “Sale price”
- Schedule the “Sale price”
- Discount for the “Sale price”
- Enter a “SKU”
- Check the “Manage stock?” box
- Check the “Sold individually” box
- Check the “Allow backorders?” box
- Select some products for “Upsells”
- Select some products for “Cross-sells”
- Product image

You can find these in the Pro version of Checklists by going to the “Checklists” screen, clicking the “Products” tab, and choosing “WooCommerce” in the left sidebar.
