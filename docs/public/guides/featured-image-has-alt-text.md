# Featured image has Alt text

With the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can require that Featured images has Alt text. This is important to make sure your posts are optimized for SEO and accessibility. If the Featured Image is missing the Alt text, you can choose to show a warning, or prevent the post from being published.

The Alt text for each image in WordPress can be set using the option shown in this screenshot:

![Featured image has Alt text](https://docs-media.publishpress.com/publishpress-checklists/image-alt-text-bdb5611972.webp)

*Featured Image Box*

- Click the “Featured Image” tab. Select the “Featured image has Alt text” option.
- You can choose from “Disabled, Recommended, or Required” options

![Featured image has Alt text](https://docs-media.publishpress.com/publishpress-checklists/featured-image-task-1-15fd2d73a8.webp)

*Featured Image*

If you enable the “Featured image has Alt text” option, it will be visible when you edit content. If your Featured image box does not have a Alt text, this task will be marked in red in the sidebar:

![Featured image alt text red](https://docs-media.publishpress.com/publishpress-checklists/featured-image-alt-text-red-5c5c4def85.webp)

*Featured Image Empty*

If your Featured image box has an image, this task will be marked in green in the sidebar:

![Featured image alt text green](https://docs-media.publishpress.com/publishpress-checklists/featured-image-has-alt-text-c22e17eb13.webp)
