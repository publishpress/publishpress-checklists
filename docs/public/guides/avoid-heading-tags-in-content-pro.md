# Avoid heading tags in content (Pro)

This feature requires the Pro version of the PublishPress Checklists plugin.

With the Pro version of the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can control which heading types are added to your posts. If the wrong headings are in a post, you can choose to show a warning, or prevent the post from being published.

- You can choose from “Disabled, Recommended, or Required” options.
- You can enter choices for the headings to prohibit. The options are H1, H2, H3, H4, H5, and H6.

![Avoid heading tags in content](https://docs-media.publishpress.com/publishpress-checklists/checklists-heading-tags-2d004c124b.webp)

If you enable this content option, it will be visible when you edit content. If your content does not have the correct headings, this task will be marked in red in the sidebar.

![Headings in content red](https://docs-media.publishpress.com/publishpress-checklists/headings-red-f9279d34b3.webp)

*Text Words Red*

If your content text has the correct headings, this task will be marked in green in the sidebar.
