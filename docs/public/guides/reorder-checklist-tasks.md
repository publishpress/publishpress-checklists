# How to Reorder Checklist Tasks

It is possible to reorder tasks inside [PublishPress Checklists](https://publishpress.com/links/checklists). This will change the order in which tasks appear in the sidebar of the post editing screen.

In the image below, you see that the “Number of words in content” task is being dragged lower down the list. You can do this by selecting the row you want to move and dragging-and-dropping it to a new location.

![Re-order checklists](https://docs-media.publishpress.com/publishpress-checklists/move-words-content-b36f6ca041.webp)

Normally the “Number of words in content” task is towards the top of the list of tasks. However, now when you go to edit a post, you will see that task is lower down in the list of tasks.
