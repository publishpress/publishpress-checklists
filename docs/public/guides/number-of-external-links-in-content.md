# Number of external links in content

With the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can require a maximum and minimum number of external links in your WordPress content. If the content does not have the correct number of external links, you can choose to show a warning, or prevent the post from being published.

We define “external links” as any `a href` link to URL on another website.

Many sites want to prevent a large number of external links because it can harm their site’s search engine optimization.

- Click the “Links” tab. The screenshot below shows the internal links option.
- You can choose from “Disabled, Recommended, or Required” options.
- You can enter choices for “Min” and “Max”.

![Number of external links](https://docs-media.publishpress.com/publishpress-checklists/number-internal-content-4c1b39367d.webp)

*External Links Task*

If you enable this external links option, it will be visible when you edit content. If you do not have the correct number of external links, this task will be marked in red in the sidebar:

![External Links Red](https://docs-media.publishpress.com/publishpress-checklists/external-links-red-42fa26e482.webp)

*External Links Red*

If you do have the correct number of external links, this task will be marked in green in the sidebar:

![External Links Green](https://docs-media.publishpress.com/publishpress-checklists/external-links-green-f47d481926.webp)
