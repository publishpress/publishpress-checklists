# Tables have a header row (Pro)

This feature requires the Pro version of the PublishPress Checklists plugin.

With the Pro version of the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can specify that all tables added to your WordPress posts have header rows. This is an important feature for the accessibility of your posts.

If table headers are missing, you can choose to show a warning, or prevent the post from being published.

- Click the “Accessibility” tab. The screenshot below shows the “Tables have a header row” option.
- You can choose from “Disabled, Recommended, or Required” options.

![Tables have a reader row settings](https://docs-media.publishpress.com/publishpress-checklists/accessibility-133f30b04e.webp)

*Number Of Words*

If you enable the “Tables have a header row” option, it will be visible when you edit a post. If your tables do not have headings, this task will be marked in red in the sidebar.

![Tables have a reader row settings red](https://docs-media.publishpress.com/publishpress-checklists/table-header-row-red-58961b168e.webp)

If your tables have headings, this task will be marked in green in the sidebar.

![Tables have a reader row settings green](https://docs-media.publishpress.com/publishpress-checklists/table-header-green-c461e80957.webp)
