# Quick Edit and PublishPress Checklists

There are “Quick Edit” settings available as part of the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin. Using these “Quick Edit” settings is recommended because this feature can be used to avoid using the Checklists requirements.

The “Quick Edit” feature is highlighted in the screenshot below. If “Quick Edit” is available, users can change the status of posts without completing the PublishPress Checklist tasks.

![Quick Edit statuses](https://docs-media.publishpress.com/publishpress-checklists/status-quick-edit-29d7548397.webp)

This next screenshot shows the settings for the “Quick Edit” feature.

![Disable Quick Edit](https://docs-media.publishpress.com/publishpress-checklists/disable-quick-edit-88609e99ef.webp)

If you enable the “Disable the “Status” option when using “Quick Edit”” option, then the “Status” option will be hidden, as in this next screenshot:

![Remove statuses option in Quick Edit](https://docs-media.publishpress.com/publishpress-checklists/hide-quick-edit-statuses-1-293fe5a2bb.webp)

If you enable the “Disable “Quick Edit” completely” option, then the “Quick Edit” option will be hidden, as in this next screenshot:

![Remove Quick Edit](https://docs-media.publishpress.com/publishpress-checklists/remove-quick-edit-6bebb69a38.webp)
