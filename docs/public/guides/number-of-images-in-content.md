# Number of images in content (Pro)

This feature requires the Pro version of the PublishPress Checklists plugin.

With the Pro version of the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can control how many images are placed in each post. If the number of images is outside the maximum and minimum number, you can choose to show a warning, or prevent the post from being published.

- Go to the Images tab. The image below shows the “Number of images in content” options.
- You can choose from “Disabled, Recommended, or Required” options.
- You can enter choices for “Min” and “Max”.

![Number of images in content](https://docs-media.publishpress.com/publishpress-checklists/images-in-content-0c230e03fc.webp)

If you enable this content option, it will be visible when you edit content. If your content does not have the correct number of images, this task will be marked in red in the sidebar.

![Number of images in content red](https://docs-media.publishpress.com/publishpress-checklists/number-images-content-red-fdea669b11.webp)

*Text Words Red*

If your content text has the correct number of images, this task will be marked in green in the sidebar.

![Images in content - green](https://docs-media.publishpress.com/publishpress-checklists/number-images-content-green-583891bace.webp)
