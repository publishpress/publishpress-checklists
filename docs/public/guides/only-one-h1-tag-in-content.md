# Only one H1 tag in content (Pro)

This feature requires the Pro version of the PublishPress Checklists plugin.

With the Pro version of the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can specify that there is only a single H1 tag in your content. This is important for accessibility and also H1. There should only ever be a single H1 tag on content pages.

If too many H1 tags are present, you can choose to show a warning, or prevent the post from being published.

- Click the “Accessibility” tab. The screenshot below shows the “Only one H1 tag in content” option.
- You can choose from “Disabled, Recommended, or Required” options.
- You can choose “Who can ignore this task?”

![Only one H1 tag in content settings](https://docs-media.publishpress.com/publishpress-checklists/accessibility-133f30b04e.webp)

*Number Of Words*

If you enable the ““Only one H1 tag in content” option, it will be visible when you edit a post. If your heading tags are not correct, this task will be marked in red in the sidebar.

![Only one H1 tag in content - red](https://docs-media.publishpress.com/publishpress-checklists/h1-tags-content-230bf5938a.webp)

If your heading tags are correct, this task will be marked in green in the sidebar.

![Only one H1 tag in content - green](https://docs-media.publishpress.com/publishpress-checklists/only-h1-content-green-b3941f8256.webp)
