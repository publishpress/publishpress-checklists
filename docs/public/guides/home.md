# The Home Screen in Tag Groups

The Home screen of the [Tag Groups](https://publishpress.com/links/tag-groups) plugin shows you an overview of all enabled taxonomies. You can unfold each of them to see an overview of the groups and the number of tags for each of them.

Behind each taxonomy you also find a link to the corresponding page where you can create and edit [tag groups](https://publishpress.com/links/tag-groups).
