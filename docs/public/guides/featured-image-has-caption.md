# Featured image has Caption

With the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can require that Featured images have a Caption. If the Featured Image is missing a caption, you can choose to show a warning, or prevent the post from being published.

The Caption for each image in WordPress can be set using the option shown in this screenshot:

![Featured Image caption](https://docs-media.publishpress.com/publishpress-checklists/caption-featured-image-9b059d52d6.webp)

*Featured Image Box*

- Click the “Featured Image” tab.
- You can choose from “Disabled, Recommended, or Required” options.
- You can choose “Who can ignore this task?”

![Featured Image has caption](https://docs-media.publishpress.com/publishpress-checklists/featured-image-caption-4d9c1ec68e.webp)

*Featured Image*

If you enable this Featured image option, it will be visible when you edit content. If your Featured image box does not have a caption, this task will be marked in red in the sidebar:

![Featured image caption is red](https://docs-media.publishpress.com/publishpress-checklists/featured-image-caption-red-85edb8b844.webp)

*Featured Image Empty*

If your Featured image box has an image, this task will be marked in green in the sidebar:

![Featured image caption is green](https://docs-media.publishpress.com/publishpress-checklists/featured-image-caption-green-837569b598.webp)
