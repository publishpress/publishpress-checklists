# Number of Characters in Image Captions (Pro)

This feature requires the Pro version of the PublishPress Checklists plugin.

With the Pro version of the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can control how the maximum and minimum length of image captons. If the number of characters in the caption is outside the maximum and minimum number, you can choose to show a warning, or prevent the post from being published.

- Go to the “Images” tab. The image below shows the “Number of characters in image captions” options.
- You can choose from “Disabled, Recommended, or Required” options.
- You can enter choices for “Min” and “Max”.

![Number of Characters in Image Captions](https://docs-media.publishpress.com/publishpress-checklists/number-of-characters-41b0adfbda.webp)

If you enable this content option, it will be visible when you edit content. If your content does not have the correct number of images, this task will be marked in red in the sidebar.

![Incorrect number of characters in caption](https://docs-media.publishpress.com/publishpress-checklists/failed-caption-characters-637875f86f.webp)

If your content text has the correct number of images, this task will be marked in green in the sidebar.

![Correct number of characters in caption](https://docs-media.publishpress.com/publishpress-checklists/correct-caption-characters-9234d112e4.webp)
