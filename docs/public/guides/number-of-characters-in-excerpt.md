# Number of characters in excerpt

With the [PublishPress Checklists](https://publishpress.com/links/checklists) plugin, you can require a maximum and minimum number of characters for the Excerpts in your WordPress content.

If the Excerpt isn’t the correct length, you can choose to show a warning, or prevent the post from being published.

[The Excerpt field is a very useful feature in WordPress](https://publishpress.com/blog/force-excerpts-wordpress/). The Excerpt is an optional summary or description of the main content.

- You can choose from “Disabled, Recommended, or Required” options.
- You can enter choices for “Min” and “Max”.

![Characters in excerpy](https://docs-media.publishpress.com/publishpress-checklists/character-excerpt-292e218698.webp)

*Excerpt Task*

If you enable the Excerpt option, it will be visible when you edit content. If your Excerpt text is not the correct length, this task will be marked in red in the sidebar:

![Excerpt Short](https://docs-media.publishpress.com/publishpress-checklists/excerpt-short-94d3bf56b1.webp)

*Excerpt Short*

If your Excerpt text is the correct length, this task will be marked in green in the sidebar:

![Excerpt Green](https://docs-media.publishpress.com/publishpress-checklists/excerpt-green-e92d9388ba.webp)

*Excerpt Green*
