# Control Who Can Edit Checklists

If users have access to the “Checklists” screen in [PublishPress Checklists](https://publishpress.com/links/checklists), they can edit the tasks that users have to complete.

You can control who has access to the “Checklists” screen by using the `manage_options` permission.

To give or remove this permission for some users, you can install [PublishPress Capabilities](https://publishpress.com/links/capabilities).

- Install the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin.
- Click “Capabilities” in your WordPress admin.
- Using the dropdown in the top-left corner, choose the role you want to modify.
- Go to the “Admin” tab and check or uncheck the “manage options” box.
